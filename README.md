# Next Generation Academy Website

Responsive static website built with HTML, CSS, and JavaScript.

## Files
- `index.html`: page content
- `styles.css`: layout and branding
- `script.js`: mobile navigation and copyright year
- `assets/academy-logo.png`: academy logo

## Publish with GitHub Pages
Upload all files and the `assets` folder to the root of your repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Wait for GitHub Pages to deploy.

Before publishing, verify all academy details and remember that public websites can be viewed by anyone. Never add passwords, API keys, or confidential student information.
